# Robot Assistant Lee

![AIVA](aiva5.jpg)

Voice-controlled local assistant with animated frontend and a Python backend for Windows actions.

## Run Locally

1. Start backend: `python server.py`
2. Open `index.html` in your browser (Edge recommended for microphone reliability).
3. Click **Start Mic** and speak commands.

## Example Voice Commands

- `move`
- `walk`
- `dance`
- `sit`
- `search ...`
- `email ...`
- `open excel`
- `close excel`
- `stop`

## Project Files

- `index.html` - UI layout
- `styles.css` - visual styles and motion states
- `app.js` - voice recognition, command parsing, UI logic
- `server.py` - local Windows command bridge/API
